HOW TO PLAY / Q&A

何をすればいい？

期限までに FINAL DIRECTIVE の要求Throughputへ到達してください。最も遅い工程が工場全体のBOTTLENECKです。

BOTTLENECKとは？

SOURCE / PROCESS / TRANSFER / ASSEMBLY / POWERのうち最も低い実効Capacityです。橙色に強調された設備を優先すると基本的に伸びます。

OVERCLOCKとは？

現在のBOTTLENECKを短時間+30%する補助操作です。連打ゲームではなく、締切前や設備投資の合間に使うタイミング技です。

MODULEとは？

周回中に自動回収するランダム強化パーツです。空きBayへ自動装備されますが、STATUS / LOADOUT から後で好きなBayへ組み替えられます。

失敗すると？

工場資産と周回Moduleは失います。ただしBlueprint / Patentで得た知識は残り、次の工場を恒久的に強化できます。

Blueprint / Patentは何が違う？

Blueprintは失敗でも得られる恒久強化資源。PatentはEra初回突破で得る希少強化です。STATUSで現在の効果を確認できます。

PAUSE / SAVEは？

PAUSE中は生産と締切時計が両方停止します。タブを隠している間も同様です。閉じていた時間のオフライン進捗はありません。

×1 / ×2 / ×4で有利不利は？

同じゲーム内時間なら経済結果は同じになる決定論的simulationです。待ち時間を短縮するため自由に変えて構いません。
